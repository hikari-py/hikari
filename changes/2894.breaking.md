Stop sending `min_values`, `max_values`, `disabled` and `channel_types` for select menu builders when they are not set, so Discord applies its own defaults. A select menu without an explicit `min_values` now requires a selection, as `min_values` was previously sent as `0`. The matching builder properties and `MessageActionRowBuilder.add_select_menu`, `add_channel_menu` and `add_text_menu` parameters are now typed as `UndefinedOr`.
